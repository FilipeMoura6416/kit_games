O algoritmo de busca do agente é o MTD(f), implementei baseado na descrição do livro IA para jogos e no artigo do autor do algoritmo Aske Plaat cujo qual nomeou o agente.

A função de avaliação é uma ponderação entre a diferença de peças imutáveis, diferença de peças de fronteira, diferença de peças e uma máscara de avaliação. 
A função compreende dois fases de jogo alterando os pesos em casa fase.
